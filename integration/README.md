# Portfolio integration overlay

Files here **overlay** the locked design kit at `design-kit/portfolio-design-kit-2026-08-08/` during `apply-portfolio-design-kit.sh`. Do not edit the design kit folder directly.

| Path | Role |
|------|------|
| `_includes/site-footer.html` | Footer shell + social icon row |
| `_includes/footer-social.html` | LinkedIn, Substack, GitHub SVG icons |
| `_data/site_settings.yml` | Contact and social URLs |
| `assets/css/footer-icons.css` | Icon-only footer styles |

Edit social URLs in `_data/site_settings.yml`.
