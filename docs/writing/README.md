## Patterns I keep coming back to

- **Decision Architecture**, how an organization decides what becomes true
- **Coordination Tax**, what you pay when everyone aligns and nobody owns the call
- **Process Theater**, motion that looks like progress
- **Operator Control Plane**, the ownership layer that keeps multi-model AI ops from fighting itself
