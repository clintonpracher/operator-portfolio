# Job Search OS

**Problem type:** FIX-SCALE — decision system applied to career search

---

## Problem

Job search at Director+ level is not a volume game. It is a judgment game: which roles deserve tailoring, which companies warrant watch-list priority, and how to protect apply velocity without drowning in noise.

I built a governed decision system — the same operating logic I use for product portfolio governance — applied to my own career search.

---

## What I built

- **0-9 scoring rubric** across three dimensions: level match, domain match, problem type (FIX-SCALE weighted highest)
- **Monitoring Queue scan** — tier-ordered company watch list with dedup and scan coverage reporting
- **LinkedIn-first discovery** — two filter sets (Remote US + LV 50mi) with keyword rotation
- **Role Radar intake** — every entry starts Status = New; I own all transitions
- **Director-Scope Exception Lane** — elevates PM roles with 2+ director signals
- **Location tier gate** — remote-first; non-LV onsite auto-skipped
- **Weekly application cap** — 6 total across all tiers
- **9 integrated skills** — strategy, resume, cover letter, outreach, tracker sync, analysis

**Meta-proof:** I built a decision system for my own job search using the same governance patterns as my business operations.

---

## Outcome / proof

| Metric | Value |
|--------|-------|
| **Governance** | Every role scored before tailoring; no ad hoc applies |
| **Dedup** | Role Radar + Job Search Tracker checked before every intake |
| **Coverage** | Every session ends with Scan Coverage block |
| **Retarget** | Platform / Data / AI at Principal–Director levels |
